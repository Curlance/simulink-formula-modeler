# 中文操作指南

当前代码已通过 121 项完整测试（0 失败、0 未完成）和第二版端到端演示。支持范围与限制以 README.md 为准。

## 启动

关闭旧工具窗口后，在 MATLAB 命令窗口执行：

```matlab
cd('path/to/simulink-formula-modeler'); % 替换为实际下载目录
launch;
```

目标环境 MATLAB R2022a。建模与提取需要 Simulink；数值与线性化分析需要 Control System Toolbox；符号分析需要 Symbolic Math Toolbox。不要仅根据工具箱安装列表判断功能可运行，以实际运行结果为准。

## 界面布局

**左侧公式区**（从上到下）：

| 界面字段 | 含义 | 示例 |
| --- | --- | --- |
| 模型名称 | 新模型名称，合法 MATLAB 标识符 | my_model |
| 状态变量（逗号） | 状态变量，按顺序 | x, v |
| 输入变量（逗号） | 外部输入，按顺序 | F |
| 参数（JSON） | 参数名与数值，或 `"symbolic"` | {"m":2,"c":1,"k":3} |
| 仿真初值（JSON） | 每个状态的初值 | {"x":0,"v":0} |
| 状态方程 | 每行一条 | der(x) = v |
| 输出表达式（JSON） | 输出名与表达式 | {"position":"x","velocity":"v"} |
| 检查并整理公式 | 校验并显示标准方程 | — |

**右侧分析区**：模型路径、分析模式、保留符号参数、状态工作点（JSON）、输入工作点（JSON）、要求平衡点。

**底部操作**：导出公式、生成模型、打开模型、提取模型方程、运行所选分析、保存分析结果、单位输入仿真。

## 输入语法

质量—弹簧—阻尼示例的方程：

```text
der(x) = v
der(v) = (F-c*v-k*x)/m
```

- 变量名用英文标识符，状态 / 输入 / 参数 / 输出不能重名，也不能用保留字。
- 初值 JSON 必须恰好覆盖全部状态，不能多填或少填。
- 支持加减乘除、括号、幂及 sin、cos、exp 单参数函数。
- 输出表达式直接引用状态、输入或参数，不能引用其他输出别名。
- 输入区不是 MATLAB 命令窗口：不接受脚本、索引、字段访问或自定义函数调用。
- 允许的幂与函数会在模型生成和反向提取中覆盖；未支持的写法会被明确拒绝。

## 操作流程

1. **检查并整理公式**：校验当前输入并显示标准方程。出错时保留输入，按结果区中文提示修正。
2. **导出公式**（需求 B）：生成 `equations.txt`、`equations.tex`、`report.md`，不要求先建模型。LaTeX 为完整中文文档，用 XeLaTeX 编译。
3. **生成模型**：按当前公式生成新模型，默认写入 `artifacts/exports`，不覆盖已有文件。
4. **打开模型**：打开模型路径字段指向的模型，可在 Simulink 中继续编辑。
5. **提取模型方程**（需求 A）：读取模型的实际模块、参数和连线，把结果填回左侧编辑区，并重置工作点字段。只支持规定范围，不支持结构会报错。
6. **运行所选分析**（需求 C）：按当前分析模式执行。
7. **保存分析结果**：按当前输入重新计算后写入文本、LaTeX 与 MAT，避免保存过期结果。
8. **单位输入仿真**：读取所选实际模型，按其初值运行 0–5 秒、各输入恒为 1 的仿真，显示曲线、保存数据与图片，并比较模型与独立积分的方程解。默认各输入为 1；程序接口可用 `options` 指定时长与各输入常值。

模型与编辑区不会自动同步：改模型后重新提取，改公式后重新生成。分析按钮读取左侧当前公式，不读取右侧模型路径。

## 三种分析模式

### 数值传递函数

参数必须为有限实数。输出状态空间矩阵、各通道传递函数、变量顺序与零初始条件说明。含 `"symbolic"` 参数时该模式会明确报错，请改用符号模式。

### 符号参数传递函数

- 「保留符号参数」留空 = 全部参数保留为符号。
- 填 `m,k` = 只保留这两个，其余已赋值参数代入数值。
- 声明为 `"symbolic"` 的未赋值参数在任何情况下都保持符号，不会被占位数值替换。
- 输出符号 A/B/C/D、传递函数矩阵、各通道、零初值约定与参数成立条件。
- 拉普拉斯变量会自动避开与参数重名（依次尝试 `s`、`s_laplace` 等），结果字段为标量 `sym`。

### 非线性工作点线性化

在状态工作点与输入工作点 JSON 中填写完整变量值（示例会预填一组供验证流程使用，切换公式后请重新核对变量名与数值）。

- 工作点与左侧「仿真初值」是两回事，分别设置。
- 默认勾选「要求平衡点」；不是平衡点会报错并给出残差。
- 取消勾选后返回带 `f0` 漂移项的仿射局部展开，此时不给传递函数，避免误报。
- 结果包含实际工作点、A/B/C/D、`f0`、`y0`、平衡残差与局部近似说明。
- 它是工作点附近的小扰动近似，不是非线性系统的全局替代。

## 示例用途

- 一阶系统：基本流程检查。
- 质量—弹簧—阻尼：两个状态、位置与速度输出。
- 耦合多输入系统：多状态、多输入与端口顺序。
- 非线性工作点示例：`der(x) = -a*x^3+u`，输出 `x^2`，预填平衡工作点 `x=1, u=1`。
- 符号参数示例：`m、c、k` 声明为 `"symbolic"`，用于符号推导与中文导出。

以上均为演示与测试案例，不代表实际应用场景。
