# 第二版功能使用方式

第二版已完成集成并通过 121 项完整测试与端到端演示，退出码 0。首版源码备份保存在 `artifacts/backups`。支持范围与限制见 README.md 与 docs/verification-report.md。

## 打开中文界面

先关闭旧工具窗口，再在 MATLAB 命令窗口执行：

```matlab
cd('path/to/simulink-formula-modeler'); % 替换为实际下载目录
launch;
```

左侧依次填写模型名、状态变量、输入变量、参数 JSON、仿真初值、状态方程和输出表达式。英文变量名和表达式语法保持不变；按钮、提示、状态及结果说明采用中文。

右侧模型路径对应「打开模型」「提取模型方程」「单位输入仿真」。分析按钮使用左侧当前公式；对现有模型分析时先提取方程。工作点与仿真初值各自独立。

## 符号参数传递函数

选择「符号参数示例」，或把分析模式切到「符号参数传递函数」。

- 参数仍可填写数值；「保留符号参数」留空时全部参数在推导中保留为符号。
- 要混合数值与符号，可在「保留符号参数」填 `m,k`；其余有数值的参数代入数值。
- 尚无数值的参数可以填精确字符串 `"symbolic"`，例如 `{"m":"symbolic","c":"symbolic","k":"symbolic"}`。未赋值参数不会以占位数值充当真实数据。
- 点击「运行所选分析」，查看状态空间、各输入输出通道、零初值约定和参数成立条件。
- 「保存分析结果」会根据当前输入重新计算，然后写入文本、LaTeX 和 MAT。

含未赋值参数时，「检查并整理公式」和「导出公式」仍可使用。生成模型、数值仿真及工作点线性化需要给参数填写数值。

## 非线性工作点线性化

选择「非线性工作点示例」，分析模式为「非线性工作点线性化」。在状态工作点和输入工作点 JSON 中填写完整变量值，再执行分析。示例预填了一组工作点供验证流程使用；切换公式后应重新核对变量名和数值。

默认勾选「要求平衡点」。系统会检查状态导数残差；若不是平衡点，会明确提示。取消勾选后，可以查看带漂移项的局部仿射展开，但不把它当作平衡点传递函数。

结果包括实际工作点、A/B/C/D、原系统在工作点的状态导数和输出值、平衡残差、小扰动关系和局部近似说明。不能将小扰动模型当作非线性系统的全局精确替代。

## 复杂模型提取

选择可信本地 SLX 后点击「提取模型方程」。支持嵌套普通子系统（多端口）、Goto/From 路由（含作用域歧义检测）、Terminator、SISO Transfer Fcn 与 SISO 多状态 State-Space，输出保留状态到实际模块路径的 `sourceMap`。完整支持矩阵见 `docs/model-support.md`。

不支持的结构会明确报告模块全路径与原因，不会只解析一部分却声称模型完整。模型加载可能运行文件内的 MATLAB 回调，因此只打开可信本地模型；公式输入的受限解析不等于 SLX 文件安全沙箱。

状态名会包含嵌套路径（例如 `Plant_Dynamics__position`）。提取后工作点字段会按新状态名和零输入重置，执行线性化前请核对。

## 导出

中文「导出公式」生成 `equations.txt`、`equations.tex` 和 `report.md`，默认目录为 `artifacts/exports`。`equations.tex` 是完整中文文档，可用 XeLaTeX 与 ctex 编译。本机已实际编译数值公式、符号推导和线性化三份 LaTeX，各生成一页 PDF，证据见 `docs/verification-report.md`。
